Índice

Qué es el DOM

El árbol de objetos que el navegador construye a partir del HTML.

Seleccionar elementos

querySelector y querySelectorAll, con selectores de CSS.

Cambiar el contenido

textContent para texto; innerHTML solo con contenido propio.

Crear elementos

createElement, append y remove.

Cambiar el aspecto

style para valores calculados y classList para el resto.
